A desktop version of the apple-box puzzle, where you drag boxes around numbers that add up to ten.

I also tried training a DQN agent to play it. A hand-written algorithm ended up scoring better, so the reinforcement learning version is parked.

- Game: [github.com/cgw0331/Fruit_Box\_](https://github.com/cgw0331/Fruit_Box_)
- DQN experiment: [github.com/cgw0331/fruitGamebyDQN](https://github.com/cgw0331/fruitGamebyDQN)
